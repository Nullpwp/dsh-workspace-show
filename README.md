# 工作区显示（dsh-workspace-show）

在左侧栏「工作区」列表右上角的**视图选项**菜单（滑块图标）里新增「显示工作区」分组，直接在这里勾选或去掉勾选每个工作区，控制它是否显示在侧栏列表中。

## 用法

1. 打开左侧栏的「工作区」区域。
2. 点击列表右上角的**视图选项**按钮（滑块图标）。
3. 滚动到菜单底部的新分组「显示工作区」：每个工作区一行，行首是文件夹图标，行尾的对勾表示当前显示。
   - 去掉勾选：该工作区从侧栏列表中隐藏；
   - 重新勾选：恢复显示；
   - 有隐藏项时，分组末尾会出现「全部显示工作区」。
4. 选择保存在当前浏览器（`localStorage`），对所有会话生效。

> 当前是「单列表」显示时，侧栏没有工作区分组可隐藏，菜单里会提示：隐藏设置会在切回「按工作区」后生效。

## 原理与边界

- 视图选项菜单由 DSH 自带的工作区组件渲染，没有提供扩展槽位。本插件把「显示工作区」分组以 React portal 挂进该菜单的条目容器；菜单本身与自带条目保持不变。
- 菜单通过 CSS 锚点识别，不依赖界面文字：视图选项菜单的触发器在侧栏标题栏里，而它的列表通过 portal 挂到 `body`，两边共享同一个 `anchor-name` / `position-anchor` 值。若锚点结构变化，还会用各语言版本的「分组方式」标签作为兜底。
- 隐藏只给渲染出来的工作区分组容器（带 `--dsh-workspace-indent` 内联样式的那一层）打标记并隐藏；工作区的注册记录、会话、历史记录、路径都不受影响。
- 关闭或停用插件时，所有标记随插件一起移除，被隐藏的工作区立即恢复。
- 在「工作区分组树」模式下，隐藏父级工作区会连同其子工作区一起隐藏；菜单里子工作区会变暗并提示父级已隐藏。
- 平铺会话列表、搜索结果和工作区选择器不做过滤。
- 依赖的 DOM 契约（菜单锚点、`data-sidebar-workspace-header`、`data-row-key="workspace:<id>"`、`--dsh-workspace-indent`）由 `test/contract.test.mjs` 对照安装版本检查。

## 文件

| 文件 | 说明 |
| --- | --- |
| `client.js` | 全部界面逻辑：菜单分组注入、工作区勾选、持久化、中英文案 |
| `index.js` | Host 半部（空实现，只为让 bundle 条目可挂载） |
| `cordis.patch.yml` | 插入 `dsh-workspace-show` 插件行 |
| `locale/en.json`、`locale/zh.json` | 插件列表与详情页的标题、描述 |
| `icon.svg`、`docs/` | 插件图标与详情页功能图 |

## 开发

```sh
node --check client.js
node test/contract.test.mjs
```
